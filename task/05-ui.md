# 05 — UI

> The page lives in `lib/src/connect_four_page.dart`. It may import
> `package:flutter/*`, `package:flutter_svg/*`, `package:game_assets/*`,
> and the state file from `04-logic.md`.

## Widget tree (high level)

```
Scaffold
└── GameAppBar (or custom AppBar)
    └── title, score, restart
└── Body
    └── GameAppBar with title 'Connect Four', turn indicator (red/yellow dot + label)
    └── Above-board row of 7 IconButton tap targets (transparent), one per column, only enabled if validDrops() contains that column
    └── Board: Stack of 42 SvgPicture widgets positioned in a 7×6 grid; each renders the board background plus a piece on top if occupied
    └── Drop animation: AnimatedPositioned with the dropping piece falling from above the board into its row
    └── On win, the 4 winning pieces are swapped to their `_winner` variant and pulse
    └── Mode-select screen: 2 large buttons (vs AI, 2P)

## Grid

7 cols × 6 rows, ~420 px square.

## Layout strategy

- Use `LayoutBuilder` to compute the board size from the available
  width, then center it with `Center`.
- Wrap the board in `AspectRatio(aspectRatio: ...)` so it stays
  square across orientations.
- On landscape phones, switch to a side-by-side layout: board on
  the left, move list / score panel on the right.

## Animations

- Tile placement: `AnimatedPositioned` 200 ms `easeOutCubic`.
- Tile merge: `AnimatedScale` 1.0 → 1.15 → 1.0 over 200 ms.
- Page transitions: handled by the wrapper; nothing to do.

## Theming

Use `buildGameTheme(Brightness.light)` from `game_assets` so the
hub stays visually consistent:

```dart
@override
Widget build(BuildContext context) {
  return Theme(data: buildGameTheme(Brightness.light), child: ...);
}
```

If the game needs a darker board (chess, minesweeper), override
`Theme.of(context).scaffoldBackgroundColor` locally.

## Empty / loading / error states

Every page must handle three cases:

- **Empty**: first launch — show a friendly "Tap to start" CTA.
- **Loading**: state is initializing (e.g. loading word list) —
  show a `CircularProgressIndicator` centered.
- **Error**: an unrecoverable error (e.g. missing asset) — show a
  red-tinted card with the error text and a 'Retry' button.

## Accessibility

- All interactive elements are `Semantics(button: true, label: '...')`.
- Color is never the only signal (add icon or text).
- Minimum touch target: 48×48 dp (use `IconButton.filledTonal` or
  wrap in `SizedBox`).
- Respect `MediaQuery.textScaler` — don't use fixed font sizes.
